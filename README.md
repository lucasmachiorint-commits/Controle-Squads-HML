# 🚀 EmanaPay - Plataforma de Gestão de Squads & Integração Jira

Aplicação Web desenvolvida em React + TypeScript para gestão de demandas de squads (Dados, Operações, RPA), triagem e gestão visual de atividades.

---

## ⚡ URL Pública Gratuita no GitHub Pages (100% Estático)

Esta aplicação foi compilada para funcionar **100% estática diretamente no GitHub Pages**, sem precisar do Render ou de qualquer outro serviço pago/externo.

### Como Ativar a URL Pública no seu Repositório (Leva 10 segundos):

1. Acesse o seu repositório no GitHub: **[lucasmachiorint-commits/Controle-Squads](https://github.com/lucasmachiorint-commits/Controle-Squads)**
2. Clique na aba **Settings** (Configurações) no topo do repositório.
3. No menu lateral esquerdo, clique em **Pages**.
4. Em **Build and deployment**:
   - **Source:** Escolha `Deploy from a branch`
   - **Branch:** Selecione `main`
   - **Folder:** Selecione `/docs`
5. Clique no botão **Save**.

🎉 **Sua URL pública ficará ativa em:**
👉 **`https://lucasmachiorint-commits.github.io/Controle-Squads/`**

---

## 💻 Execução Local

```bash
# 1. Instalar dependências
npm install

# 2. Executar aplicação localmente (React Vite)
npm run dev

# 3. Gerar nova build estática para o GitHub Pages (pasta /docs)
npm run build
```
